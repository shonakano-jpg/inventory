          店舗マスタ

          棚卸しセッション作成時に選べる店舗。追加・削除できます。

            クラウド共有（Supabase）必須

            全端末・全店舗でリアルタイムに在庫を共有します。各端末で一度URLとanonキーを設定してください。

            セットアップ手順
            1. supabase.com で無料プロジェクトを作成
            2. SQL Editor を開き、配布の supabase-schema.sql を貼って実行
            3. Project Settings → API から Project URL と anon public key をコピー
            4. 上の欄に貼って「接続して保存」

            データ

            「全ての棚卸しデータを消去」は、全店舗・全端末の棚卸し（セッション・読取・ラック確認）を消します。商品マスタと店舗マスタは残ります。元に戻せません。
