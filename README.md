# 古着棚卸し PWA

スマホのカメラで**インハウスコード（値札バーコード）を読み取って棚卸し**するWebアプリ(PWA)です。
インストール不要・iPhone/Android両対応。**複数店舗・複数端末でリアルタイム共有**できます。

## 特長

- 📷 カメラでバーコード読取（値札はJAN-13(EAN-13)店内コード。誤読低減のため対応形式を最適化）
- ⌨️ 手入力・外付けバーコードスキャナにも対応（**数量もまとめて入力可**）
- 🏷 **バーコードが無い在庫**は、カテゴリ×価格をマスタから選び「**Tシャツ 2,980円 ×50**」のように点数入力
- 🏬 **複数店舗**：店舗マスタから選んでセッションに紐付け。**公式店舗リスト30店舗（NOTIME/SELFURUGI）を収録**、追加・削除も可
- 📦 **ロケーション大分類**：店内在庫 / バックヤード在庫 / その他倉庫 を切替えて計上
- 🧮 インハウスコード＝カテゴリ×価格なので**数量カウント**（同じコードを何点でも加算）
- 📊 **店舗別レポート**：各店舗の合計点数一覧 → 店舗をタップで「店内 / バックヤード / その他倉庫」の内訳、
  さらに**カテゴリ比率**・**価格帯比率**を表示。CSV書出（全店舗／店舗別）
- 👤 担当者名を記録（誰が読み取ったか）
- 👥 クラウド共有（Supabase）で全端末・全店舗がリアルタイム同期
- 📴 オフラインでもアプリ起動（Service Worker）
- ✅ 付属の商品マスタ（`master.csv` = インハウスコード278件）を**初回自動読込**

## いちばん簡単な公開手順（クラウド / ドラッグ&ドロップ）

PCにアプリを置きっぱなしにせず、クラウドに公開して各自のスマホから使えます。自動でHTTPSになるのでカメラも動きます。

### 方法A：Cloudflare Pages（無料・推奨）
1. [dash.cloudflare.com](https://dash.cloudflare.com) にサインアップ／ログイン
2. **Workers & Pages → Create → Pages → Upload assets**
3. この `furugi-inventory` フォルダ（または `furugi-inventory.zip` を展開した中身）を**まるごとドラッグ&ドロップ**
4. 発行された `https://xxx.pages.dev` をスマホで開く → ブラウザメニューの「**ホーム画面に追加**」

### 方法B：Netlify Drop（無料・アカウント不要でお試し可）
1. [app.netlify.com/drop](https://app.netlify.com/drop) を開く
2. フォルダをドラッグ&ドロップ → 即URL発行（保持にはログイン）

> どちらも `git` もコマンドも不要です。

## クラウド共有（複数端末・複数店舗で同じデータ）

公開しただけでは各端末バラバラ保存です。**全端末で共有**するにはSupabaseを繋ぎます。

1. [supabase.com](https://supabase.com) で無料プロジェクト作成
2. SQL Editor に `supabase-schema.sql` を貼って実行
3. Project Settings → API の **Project URL** と **anon public key** をコピー
4. アプリの「設定」画面に貼って「接続して保存」→ バッジが「クラウド共有」になれば完了
5. 各端末で同じURL/キーを設定（設定は端末ごとに1回）。以後、店舗・棚卸し・読取がリアルタイム同期

> 商品マスタも一度「マスタ→CSV取込」でクラウドに入れれば全端末に反映されます。
> セキュリティ：初期スキーマは「anonキーを知る人は読み書き可」の店舗内向け構成です。社外配布時はSupabase Authでポリシーを絞ってください。

## 使い方

1. **スキャン** → 「＋新規」で**店舗**を選び棚卸しセッションを作成（店舗は設定の店舗マスタから）
2. 上の **店内 / バックヤード / その他倉庫** を選択（読取先ロケーション）
3. 「カメラ開始」で値札バーコードを次々スキャン（同じコードは数量が加算）
4. 数量が分かっている在庫は、手入力欄にコード＋数量、またはバーコード無しなら
   「🏷 バーコードが無い在庫を選んで数量入力」でカテゴリ×価格を選び **点数を入力**（+5/+10/+50ボタンあり）
5. **レポート** → 店舗別の合計を確認 → 店舗をタップでロケーション内訳・カテゴリ比率・価格帯比率、結果CSV書出

### 店舗マスタの管理
「設定 → 店舗マスタ」で店舗を追加・削除できます。初回は公式30店舗（NOTIME/SELFURUGI）を自動収録。
「公式店舗リストを読込」でいつでも再取込できます（クラウド接続中なら全端末へ反映）。

## 商品マスタ（インハウスコード）

`master.csv` に添付のインハウスコード（カテゴリ×価格＝バーコード）278件を収録済み。初回起動時に自動で読み込みます。
更新する場合は「マスタ→CSV取込」。フォーマット（日本語見出しも自動認識）：

```csv
sku,name,category,price,expected
2300001015002,デニム ¥1490,デニム,1490,
```

| 列 | 別名 | 意味 |
|----|----|----|
| sku | バーコード / コード / インハウスコード / jan | バーコード（必須） |
| name | 商品名 | 表示名 |
| category | カテゴリ / 分類 | 分類 |
| price | 単価 / 価格 | 価格 |
| expected | 想定数 / 在庫数 | 任意（空でOK） |

## ローカルで試すだけの場合

```bash
cd furugi-inventory
python -m http.server 8000
```

同じPCなら `http://localhost:8000`。ただし**スマホのカメラはHTTPSが必須**なので、実運用は上の公開手順を使ってください。

## ファイル構成

```
index.html   画面
styles.css   スタイル
app.js       アプリ本体（画面制御・CSV・レポート）
db.js        データ層（ローカル/Supabase切替・リアルタイム）
scanner.js   バーコード読取（getUserMedia＋zxing-wasm）
config.js    既定の接続設定（任意）
sw.js        Service Worker（オフライン対応・自動更新）
manifest.webmanifest   PWA設定
master.csv             インハウスコード278件（初回自動読込）
stores.json            公式店舗30件（初回自動読込）
supabase-schema.sql    クラウド用DBスキーマ
```
